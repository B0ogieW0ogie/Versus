# 🚀 Versus — Визитка проекта

## 1. Что это такое

**Versus** — это платформа, где люди спорят, голосуют и зарабатывают на мнении большинства.

Пользователи:

- выбирают сторону в баттле (A vs B)
- ставят токены
- аргументируют свою позицию
- зарабатывают, если оказались на стороне большинства

👉 Это **рынок влияния**, а не рынок правды.

---

## 2. Основная идея

В интернете люди уже спорят бесплатно.

**Versus превращает споры в экономику:**

- мнение → ставка
- аргумент → инструмент заработка
- аудитория → капитал

---

## 3. Как это работает

### 1. Создаётся баттл

Пример:

- Messi vs Ronaldo
- iPhone vs Android
- Marvel vs DC

### 2. Пользователь голосует

- ставит токены на одну сторону
- токены блокируются

### 3. Пользователь влияет

- пишет комментарий
- делится своей ссылкой
- убеждает других

### 4. Формируется пул

- все ставки собираются в один банк

### 5. Баттл завершается

- выигрывает сторона с большим весом голосов

### 6. Выплаты

- победители делят пул
- проигравшие теряют часть средств

---

## 4. Экономика

**Распределение:**

- 88% → победителям
- 5% → проект
- 3% → сжигание
- 4% → reward / insurance pool

**Важно:**

- есть риск → есть ценность голоса
- есть reward → есть мотивация участвовать
- есть защита → система не убивает новичков

---

## 5. Уникальные механики

### 🔒 Скрытое голосование

- видно только общий пул
- нельзя увидеть, кто лидирует

👉 убирает "эффект толпы"

### 🧠 Аргументы = деньги

- комментарии влияют на решения
- лучшие аргументы приносят доход

### 🔗 Реферальная система

- у каждого есть своя кнопка голосования
- можно зарабатывать на привлечённых голосах

👉 но:

- только если они победили

### ⚖️ Анти-кит механика

- большие ставки дают меньше влияния за токен

👉 невозможно "купить победу"

### 🛡 Reward / Insurance Pool

- частичный возврат проигравшим
- бонусы за активность

👉 снижает риск ухода пользователей

## 14. Dev setup (MVP)

Стек: Laravel 13 · Livewire 4 · Filament 5 · Blade · Tailwind · PostgreSQL 16 · Pest · Larastan. Весь dev-окружение — в Docker.

### Prereqs

- Docker Desktop (или Colima/OrbStack) + `docker compose`
- Порт 80 свободен
- В `/etc/hosts` добавить: `127.0.0.1 versus.local`

### Быстрый старт

```bash
make up                    # поднять nginx/php/postgres/workspace
make composer install      # PHP-зависимости
make npm install           # Node-зависимости
make npm run build         # собрать Vite
make art key:generate      # APP_KEY
make migrate               # миграции
make art db:seed           # admin + 2 демо-баттла
```

Приложение — <http://versus.local/>, админка — <http://versus.local/admin>
(seed-admin: `admin@versus.test` / `password`).

Полезные команды:

```bash
make ws          # bash в workspace-контейнере
make test        # Pest (47 тестов)
make stan        # Larastan level 6
make pint        # стиль
make fresh       # migrate:fresh --seed
```

Cron-settlement крутится через `battles:settle-due` every minute — запускай
`php artisan schedule:work` в workspace-контейнере, либо `make art battles:settle-due`
вручную для проверки.

### Что вошло в V1

- Core: баттлы, голосование, пул, settlement (88/5/3/4), выплаты
- Комментарии (плоские)
- Реферальные ссылки + cookie-атрибуция + реферальный бонус из reward pool (10%)
- Filament-админка: CRUD баттлов, просмотр юзеров с Grant tokens, аудит transactions

### Что НЕ входит в V1

- Скрытое голосование (commit-reveal)
- Анти-кит формула (`weight` сейчас равен `amount`)
- On-chain интеграция
- Стриминг баттлов
- Модерация пользовательских баттлов — их создаёт только админ
- Мобильное приложение
